RIXONGILE CONSTRUCTION (PTY) LTD — WEBSITE PACKAGE
===================================================

FILES
- index.html      Homepage
- about.html      Company introduction
- contact.html    Contact details, embedded map and WhatsApp quote form
- styles.css      Responsive visual design, animations and 3D hover effects
- script.js       Mobile menu, reveal animation, 3D tilt, gallery lightbox and WhatsApp form
- assets/         Supplied company logo and supplied solar installation photographs

HOW TO PREVIEW
1. Extract the ZIP file.
2. Keep the assets folder beside the HTML pages.
3. Open index.html in Chrome, Edge or Firefox.
4. Internet access is needed for Google Fonts, embedded Google Maps and the externally hosted construction stock-photo backgrounds.
